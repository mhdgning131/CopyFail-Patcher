# Patcher script for CVE-2026-31431

---

This repo provide script for the CopyFail vulnerability, for Debian/Ubuntu/RHEL/Fedora, didn't test on other distros but anyway...

Just follow these :

```bash
~$ git clone https://github.com/mhdgning131/CopyFail-Patcher.git
~$ cd CopyFail-Patcher
~$ chmod +x patchcopyfail.sh
~$ ./patchcopyfail.sh
```

Provided also a remove script so you'll be able to remove the patch if you want (for testing i guess)
